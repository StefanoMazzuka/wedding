# Vuestras fotos

Sube aquí `portada.jpg`, `foto-01.jpg`, etc. Después indica sus nombres en `config.js`, en `cover` y `photos`.

Los nombres distinguen mayúsculas de minúsculas. Usa nombres sin espacios ni acentos.
Recomendado: JPG o WebP, unos 1600 píxeles de ancho y menos de 500 KB por foto.
Las fotos se recortan visualmente a formato cuadrado en la galería; conserva las caras cerca del centro.
Si todavía no hay fotos, la web muestra una composición decorativa y espacios para recuerdos.
